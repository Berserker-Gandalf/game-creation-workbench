# v0.17.0 — Persistent conversation controls & bilingual workbench

造物间 / ZAOWU 是本机单用户的游戏创作与项目管理实验工作台，支持简体中文 / English，源码采用MIT许可。

本版提供按会话持续保存的“允许修改”开关，以及模型旁的推理强度选择。刷新或重开会话后继续沿用，取消勾选后关闭；新建、复制或恢复不继承执行授权。只读项目分析不改变保存的开关。

Codex选项来自其模型能力目录；OpenAI/DeepSeek Responses传递`reasoning.effort`，具体模型支持以服务响应为准。切换服务/模型重置默认，不支持的强度不自动降级或重试。

同时修正英文草稿和快照说明误翻译，以及项目选择存储异常导致启动/加载失败的问题。整理中英文GitHub首页、项目介绍、使用和发布说明，保留此前原创LOGO、任务交付与工程留存能力。

验证：189项Python测试、语言检查和生产构建通过；隔离浏览器验证持久开关、强度与原文。请求协议测试使用模拟服务，没有新增真实模型、收费生成、引擎运行或远端GitHub验收。构建仍提示主界面/3D分块较大。

ZIP包含源码与预构建界面；需要Python后端依赖，部分功能需要Node及自行安装的创作工具。不是独立安装器。首次使用见[README](../README.md)、[英文首页](../README_EN.md)和[会话控制](CONVERSATION_CONTROLS.md)。

使用自己的账号和API Key；模型、服务、引擎及用户资产分别遵循原有授权。保留已有数据目录，不将本机服务暴露到公网。请核对附件SHA-256后使用。
