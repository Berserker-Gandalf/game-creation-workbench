# 官网动态交互与功能截图

日期：2026-10-28。延续墨绿与暖铜视觉，通过轻量原生 CSS 与 JavaScript 增加层次；不新增框架、动效库或第三方网络依赖。

2026-10-29 品牌更新：当前官网的 12 张中英文大图与 8 张缩略图已全部补拍/生成游织工坊 Questweft 版本，原有验证记录保留为历史快照。当前品牌与兼容范围见 [品牌说明](BRAND_AND_SEARCH.md)。

## 页面变化

- **首屏功能展示**：项目空间、任务看板、音乐与建模四张缩略图，点击或使用方向键选择。大图、标题、页码与选中状态同步；选择首屏图片不会改变下方功能展示的选择。
- **完整功能展示**：项目空间、设计资料、任务、音乐、角色建模与 WebUI 硬件预检共六页。支持方向键循环、Home / End、截图对话框、原图查看及 Escape 关闭。
- **滚动反馈**：标题、能力卡、上手步骤和下载区分段进入；约 600 ms 的透明度与小幅位移动画，每组最多 130 ms 的错峰。顶部细线显示阅读进度，导航标记当前区段。页面保持原生滚动。
- **鼠标反馈**：主要按钮微抬升与窄幅光泽、箭头位移、导航下划线、截图缩略图强调、下载卡边框光感。首屏截图随精确鼠标指针移动产生轻微倾斜与局部光感，最大倾角约 1.2° / 1.6°，离开后复位。
- **图片切换**：图片加载后约 420 ms 淡入；不自动播放，不定时轮播。保留访客主动选择与阅读时间。

## 控制与性能

页脚“动态效果”按钮可关闭移动、入场和截图淡入，选择保存在当前浏览器；关闭时所有内容立即可见，页面回到直接滚动。系统启用“减少动态效果”时，网站自动关闭动效，此时按钮说明遵循系统设置，不允许网页覆盖系统偏好。

触屏设备不依赖悬停或倾斜操作。320 / 375 px 等窄屏首屏缩略图为两列，完整功能标签按宽度重排；语言、下载与原图操作保持可达。

滚动与指针更新使用 `requestAnimationFrame` 合并，滚动监听采用被动方式。入场元素只展示一次，进入后取消观察；没有持续轮播计时器。首屏缩略图使用独立的 320×180 文件，避免为缩略图下载整张功能截图。大图仍保留 1280×720 尺寸，非首屏图片延迟加载。

## 截图来源与边界

本轮补拍设计资料、任务、音乐和角色建模的中英文截图，共 8 张，来自当前 v0.19.0 界面与隔离的 Northstar 示例数据。截图仅展示实际界面和本机示例资料，不代表引擎验收、真实模型响应、音乐生成、自动绑定或 Tripo 生成已完成。音乐截图显示可选服务未连接，模型名属于截图时界面的接口契约，不是实时账户模型目录。

项目空间和硬件预检沿用原有中英文验证截图。所有大图均检查为 1280×720，首屏另生成 8 张轻量缩略图。截图使用原始界面，不绘制不存在的产品界面，也不修改已有项目运行数据。

官网继续没有案例视频播放器、视频入口、自动播放音频或案例媒体文件；案例视频位于 Pages 来源目录之外。

## 验证与维护

`node --test tests/website.test.mjs tests/beacon-route.test.mjs` 检查双语、两个图库的独立目标、文件与缩略图尺寸、下载元数据和无视频边界。构建、Python 回归与公开文件检查继续使用仓库既有流程。

浏览器检查范围包括两组图库的方向键循环、选中状态独立、原图地址、关闭对话框后的焦点、动效开关持久化、滚动入场与导航状态，以及中英文在 320–1440 px 和手机横屏下无横向页面溢出。系统减少动态效果的分支通过源码检查，未修改操作系统设置；最大系统文字缩放、完整屏幕阅读器与真实触屏硬件仍未独立验收。
