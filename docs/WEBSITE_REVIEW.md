## 两项 Skill 的使用

- **UI UX Pro Max**：使用本地 `focus not obscured`、`responsive navigation mobile`、`touch target spacing` 和 `image layout shift` 检索。采用与网页相关的焦点可见、响应式与触控建议；不将手机原生单位规则当作网页认证标准，不重新生成或覆盖既有设计系统。
- **Web Asset Generator**：调用已安装技能中的校验函数，复核分享图尺寸、格式、文件大小及主要文字对比度；独立核对 favicon、ICO 和手机图标尺寸、透明度。现有素材符合本轮检查，保留原图，不重复生成。

两项 Skill 的原始来源与版本见 [设计规范](WEBSITE_DESIGN.md)。本轮未添加依赖、外部字体、跟踪服务或付费图片请求。

## 验证结果

- 中英文分别检查 320×812、375×812、640×768、768×1024、812×375、1024×768、1440×960；没有横向页面溢出，下载主按钮高 52 px。
- 浏览器实测键盘跳到正文、截图 End 键切换、原图地址同步、Escape 关闭并返回原按钮、语言切换后刷新保留选择。
- 使用仅本机的故障响应验证：10 秒慢响应在 8 秒超时后回退、HTTP 503 回退、空发布元数据回退。没有触发实际下载或创作 API，也没有修改线上发布。
- 15 项 Node 测试通过，其中新增请求选项、HTTP/JSON 错误和请求／响应体超时回归检查。
- 215 项 Python 测试通过；前端构建通过，保留原有大文件包提示。它们验证项目回归，不代表外部账号、引擎或安装包重新验收。
- 22 项素材和主要配色检查通过；ICO 三种尺寸由既有 Node 检查覆盖。主要配色对比度约 5.2:1–14.6:1，非完整无障碍认证。
- 案例视频、配音和动图仍位于 Pages 来源目录之外；网站没有播放器或案例视频入口。

本轮未改变系统减少动态效果或文字缩放设置；减少动态效果规则已检查，系统最大文字缩放、完整屏幕阅读器流程和外部社交平台实际抓取仍需独立验证。

## 上传与后续

本轮结果为本机验证版本。上传最新官网更新包中的 `docs` 文件夹，并等待 GitHub Pages 部署成功后，线上才会生效；不需要替换已有 v0.19.0 安装包。

上线后检查正式地址、三类下载与校验链接、分享图 HTTPS 可访问性。外部平台通常抓取静态 HTML，本次界面语言切换不产生独立英文网址，不能保证平台按访客所选语言生成分享卡。若后续需要完整双语搜索与分享入口，可再增加独立英文页面，避免本轮扩大改动。
