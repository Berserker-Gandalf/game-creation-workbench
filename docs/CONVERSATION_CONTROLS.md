# 会话执行与推理强度

适用版本：0.17.0。日期：2026-10-27。

## 持续允许修改

在聊天输入框下勾选“执行：允许修改（持续开启）”。选择保存到当前会话，发送消息、切换页面或负责人、刷新浏览器、重新启动工作台后继续沿用；取消勾选后回到只读讨论。每个会话分别设置，另一个会话不会自动开启。

保存完成前控件和发送按钮暂时禁用。保存失败会提示，继续保留此前已确认的选择。新建、复制、资料包恢复后的会话默认关闭执行，不继承原会话的执行授权。归档会话仍不能发送。

这个开关沿用原有角色工具范围：普通音乐/建模角色可保存其负责的方案，不因此得到任意工程命令。工作台全功能、Codex整机访问、SUNO/Tripo自动积分继续由独立授权面板控制。点击撤销授权会同时关闭本界面的执行选择；单独取消执行不删除已保存的其他权限。

“分析当前项目”仍以只读方式发送该次请求，但不会取消当前会话已勾选的执行设置。之后手动发送的消息恢复使用保存的选择。运行期间不能改变设置；停止当前运行后再调整。

## 推理强度

在输入框下方选择服务、模型及“推理强度”，默认是“模型默认”。选择保存在当前会话，切换模型或服务后重置为默认值，再按新模型选择。强度控制推理投入，不是模型名称或创作服务生成模型，也不扩大权限。

| 服务 | 选项与行为 |
| --- | --- |
| Codex会员 | 从所选模型的`supportedReasoningEfforts`读取实际选项，包括其可能声明的新强度；服务未声明时仅使用默认。发送前再次校验，传给`turn/start.effort` |
| OpenAI API | 提供协议中的`none/minimal/low/medium/high/xhigh/max`，发送为`reasoning.effort`；具体模型支持的子集由服务核验，手填模型ID不等于能力已验证 |
| DeepSeek API | 提供Responses协议的`none/low/high/max`，发送为`reasoning.effort`；旧模型或不同账号的支持以实际响应为准 |

选项含义显示中英文标签并保留协议值。API不支持某个值时明确返回错误，不静默改为其他强度、不自动重试。提高强度可能增加耗时和用量；选择“模型默认”时不发送强度覆盖，沿用服务自身设置。

接口依据：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[OpenAI reasoning guide](https://developers.openai.com/api/docs/guides/reasoning)、[DeepSeek Responses API](https://api-docs.deepseek.com/api/create-response/)。文档核对日期为2026-10-27，实际账号目录与模型支持仍需连接后确认。

## 开发接口与留存边界

`GET /api/conversations/{cid}/preferences`返回`execute`和`reasoning_effort`；`PUT`仅接受这两个字段并校验类型。偏好保存于本机SQLite的`settings`，键为`conversation_preferences:<cid>`。这是用户配置接口，没有加入Agent业务动作目录，也不会被聊天内容自动修改。

聊天请求省略`execute`或`reasoning_effort`时采用已保存值；显式`execute:false`仅覆盖当前请求，不改保存的开关。实际发送的强度记录在`runs.runtime.reasoning_effort`，Codex运行时目录验证继续保留。工具循环中的每个API请求都沿用相同强度。

资料包格式仍为10、工程快照格式仍为2；会话权限与偏好不作为可继承授权恢复，历史运行里的强度记录仍保留。76项业务动作与21项工具名称保持不变。
