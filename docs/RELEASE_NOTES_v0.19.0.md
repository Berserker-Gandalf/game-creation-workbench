# v0.19.0：自带运行时与完整上手接线

首次使用不再要求先准备 Python：新增 Windows x64 私有 CPython 发行包和图形安装器，程序与用户数据分开保存。项目、多来源、WebUI、Blender 及快照/恢复页面接入 Windows 原生选择窗口，保留手填和原有预览确认。

快速上手中的音乐选项可装配 Node 和原版 SUNO Skill 2.4.0。原包固定来源与 SHA-256，临时解包核验后启用；全局 Skill、已有凭据和音乐消费授权保留。音乐页沿用原版 helper 的网页授权验证流程。

WebUI 增加只读硬件预检，展示 RAM、显卡/可核验显存、驱动和磁盘预算，给出 SD 1.5 / SDXL 起步建议；未知信息明确标示，不修改运行环境或自动下载权重。

新增界面及工作台错误消息保留中文/English。业务动作仍为 76 项、工具名称 21 项；目录窗口和装配入口不自动开放给 Agent。

使用方法、安装位置、移除和升级步骤见 [应用与装配指南](WINDOWS_APP_AND_SETUP.md)。Windows 发布物为 `ZAOWU-0.19.0-windows-x64-setup.exe`、`ZAOWU-0.19.0-windows-x64.zip` 及校验文件；另保留源码 ZIP。

这是未签名的 Windows 10/11 x64 本地安装候选。尚无自动更新、系统应用列表卸载项或自动数据库回滚；干净虚拟机和真实收费创作仍需独立验收。完整验证证据见 [本轮记录](verification/setup-v0.19.json)。

上传准备阶段另修正了新测试的非 Windows 分支，补充运行时/生成应用文件的源码排除检查，并统一中英文首页与三种附件说明。最新源码检查见[上传准备记录](GITHUB_READINESS_2026-10-28.md)，首次预发布步骤见[发布指南](GITHUB_RELEASE.md)。
