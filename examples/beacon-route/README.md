# 灯塔航线 · Beacon Route

直接用现代桌面浏览器打开 `index.html`，不需要安装依赖。方向键或点击相邻格移动，P / Esc 暂停，R 重来。收集三枚光种后到达东北角灯塔。

Open `index.html` in a modern desktop browser. Use arrow keys or click adjacent tiles. P / Esc pauses; R restarts. Collect three light seeds and reach the northeast lighthouse. Choose English in the top right.

这是 MIT 许可的原创工作台案例，源码与关卡均在本目录。浏览器游戏不等于 Unreal / Unity 工程验收；工作台接入时的引擎选择只是后续开发目标。

规则检查：从仓库根目录运行 `node --test tests/beacon-route.test.mjs`。
